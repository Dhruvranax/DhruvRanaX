👨‍💻 About Me

I am Dhruv Rana, a Cyber Security and Digital Forensics student building practical skills in penetration testing, web application security, network security, Linux, and security automation.

My current priority is penetration testing. I spend most of my practical time working with reconnaissance, enumeration, packet analysis, web security testing, vulnerability assessment, and controlled exploitation labs.

I prefer a simple approach:

Understand the target → test methodically → verify the finding → document it → improve the defense.

🧠 Security Mindset

<div align="center">

🔎 Recon First

Understand the attack surface before testing.

🧩 Understand the System

Know how the application, protocol, and service actually work.

⚙️ Automate Repetitive Work

Use Python and Bash to reduce manual effort.

📝 Document Findings

A vulnerability is more useful when the evidence, impact, and remediation are clear.

🛡️ Stay Authorized

Only test systems and environments where you have explicit permission.

🚀 Keep Learning

Security changes continuously, so practical learning never stops.

</div>
