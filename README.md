I'm **Dhruv Rana**, a Cyber Security & Digital Forensics student building practical skill in **penetration testing**, **web application security**, **network security**, **Linux**, and **security automation**.

My current priority is **penetration testing**. Most of my practical time goes into reconnaissance, enumeration, packet analysis, web security testing, vulnerability assessment, and controlled exploitation labs.
